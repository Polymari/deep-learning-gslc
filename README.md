# GSLC Deep Learning

Repositori ini berisi implementasi praktikum dan laporan analisis komparatif untuk GSLD Deep Learning sesi 5, oleh Fergio Harjanto - 2802392412


## Repo berisi
```text
├── Tugas05_Transfer_Learning.ipynb                                      # notebook eksperimen
├── Bagian A (Analisis Konseptual).pdf                                   # Dokumen laporan analisis konseptual (Bagian A)
├── Laporan Teknis.pdf                                                   # Dokumen laporan teknis empiris (Bagian B & C)
├── README.md                                                            
├── requirements.txt                                                     # dependency python
├── metrics_log.csv                                                      # Log metrik model B1 s.d. B5 (CSV)
├── metrics_log.json                                                     # Log metrik model B1 s.d. B5 (JSON)
├── metrics_raw_epochs.csv                                               # Log mentah seluruh epoch untuk B1 s.d. B5 (78 baris)
├── metrics_b1_raw.csv s.d. metrics_b5_raw.csv                          # Log metrik mentah per-epoch individual tiap kondisi
├── learning_curves.png                                                  # Grafik komparatif Loss & Akurasi 5 Subplot
└── Tugas Take Home - Sesi 05 Advanced CNNs and Transfer Learning.pdf   # Berkas soal dan panduan tugas
```

Laporan teknis (bagian C) dan analisis konseptual (bagian A) terpisah akibat keterbatasan halaman, menjadi 2 file PDF dengan 5 page masing-masing.

## Usage

Import Notebook `Tugas05_Transfer_Learning.ipynb` ke colab.research.google.com, dan run dengan accelerator GPU T4
